# Velora 功能清单

> 状态截至 2026-08-12。对应代码实现,非规划。

## 一、文档编辑核心

### WYSIWYG 编辑器(ProseMirror + Tiptap 3)
- 所见即所得:标题/粗体/斜体/删除线/行内代码/链接,符号不外露
- 标题(1–6 级)/段落/引用/有序·无序·任务列表/表格/图片/水平线/数学公式(KaTeX 行内 + 块级)
- **Markdown round-trip**:语义无损 + 风格归一(26 项测试全绿)

### 三个自定义一等节点
| 节点 | 能力 |
|---|---|
| **Mermaid** | 6 套 Velora 主题 + 亮暗自适应;错误兜底;Inspector 改主题/导出 SVG/AI 优化 |
| **SVG** | 文件引用 + 内联两种来源;专用渲染容器(CSS 隔离);单击放大(滚轮缩放)/双击编辑源码;写回 .svg 文件 |
| **Details 折叠块** | `<details><summary>` 解析为可编辑节点,内部可放任意节点 |

### 辅助扩展
- `[TOC]` → 自动目录节点(点击跳转,实时随标题更新)
- **Typora 式原位源码标记**:光标进入粗体/标题等原位显示 `**`/`#` 标记
- **格式化快捷键**:⌘1–6 标题、⌘0 正文、⌘⌥C 代码块、⌘⌥Q 引用、⌘⌥U/O/T 列表、⌘⌥M Mermaid、⌘⌥D 折叠块

### 模式
- 视觉模式(WYSIWYG)/ 源码模式(CodeMirror,⌘/ 切换,双向序列化)

## 二、SVG 画布编辑器

**定位**:架构图/流程图的会话内几何微调(时序图留 Mermaid)。**D2 方案**:会话内磁吸,存盘干净静态 SVG。

- **五样图形**:矩形/椭圆/菱形/文字/箭头
- **磁吸连线**:边界相交精确落点(线段∩矩形/椭圆/菱形,有几何单测)
- **会话内跟随**:拖节点时连线端点重算 + 正交折线路由
- **编辑能力**:拖拽移动(从属文字/连线端点联动)/ 右下角缩放 / Undo-Redo / 框选 + ⌘多选 / 对齐参考线 / 多选对齐·分布 / 方向键微调 / 复制粘贴 / 层级 / 适应画布 / 网格 + 吸附 / 双击文字编辑 / 直角折线 / 调色盘
- **Mermaid → SVG**:AI 理解语义后重新绘制(非机械渲染),保留原始源码折叠块

## 三、AI 能力(独立 Service Layer)

- **多供应商**:Anthropic / DeepSeek / GLM Coding Plan / Kimi + 自定义(Anthropic/OpenAI 两种协议)
- 每家独立记忆 Key/模型/Base URL;内置模型清单 + 可手填
- **走 Rust HTTP 代理**(绕开 WebView CORS)
- **三层触点**:
  1. 选中文字 → 浮动工具栏(优化/翻译/总结/扩写 + 自定义指令)
  2. 选中 Mermaid/SVG → Inspector AI 改源码
  3. ⌘L AI 对话:多轮,可附当前文档/右键添加选中文字为上下文
- 设置页「测试连接」一键验证

## 四、项目管理

- **Project Explorer**:打开文件夹 → 文件树;点击打开,未保存守卫
- **左栏三标签**:文件 / 大纲 / Git 变更
- **文件监听**(notify crate):目录树/Git 自动刷新;**当前文档外部修改实时重载**(Typora 式磁盘优先)+ 写盘回声吸收
- **自动保存**(可配置间隔)+ 状态栏脏标记/外部修改提示

## 五、Git 集成(Rust git CLI)

- 变更列表(M/A/D/U 彩色标记)/ 分支显示
- 点文件名打开 / 点 diff 图标看完整 diff
- 提交(⌘Enter)/ 状态栏分支 + 变更数

## 六、工作台 UI

- **macOS 原生菜单栏**:文件/编辑/段落/格式/显示
- **顶部标题栏**:当前文件名(可拖拽窗口)
- **⌘K 命令面板**:应用命令 + 项目文件跳转
- **上下文 Inspector**:光标所在块的实时源码 + 属性面板
- **右栏 Inspector / AI 对话**双标签
- **自定义右键菜单**:按上下文变化(Mermaid/SVG/文字/空白各不同)
- **块操作手柄**:悬停浮现,按块类型出不同菜单
- **设置对话框**:通用 / AI / 快捷键(捕获式自定义)

## 七、导出

- HTML 导出(Mermaid/SVG 内联渲染,亮暗主题)

## 八、基础设施

- Design Token 系统(亮/暗,Sepia/高对比预留)
- 快捷键可自定义(localStorage 持久化)

- ADR 决策记录 3 份
